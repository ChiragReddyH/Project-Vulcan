# Project-Vulcan
### 2026-08-23

Reached out to Rocketeers (launch@rocketeers.in) about starter kit options, 
motor pricing, and legal launch sites near Bangalore.

Checked their store, browsed beginner kits and starter packs. Landed on:
- Rocket: Hurricane (beginner kit, ₹1,911-2,308)
- Motor: C6-2 (standard beginner class, 6N thrust, 2-second delay)

Chose C6-2 over B4-2/B4-0/C6-0 for the safer ejection timing, 2-second delay 
lets the rocket coast closer to actual apogee before parachute deployment, 
rather than ejecting immediately at burnout.

Confirmed Hurricane kit supports C-6-0, C-6-2, B-4-0, and B-4-2 motor options.

Next steps:
- Wait on Rocketeers response re: launch site
- Order Hurricane kit + C6-2 motors once site is confirmed
- Talk to a Physics teacher about school involvement/launch permission
